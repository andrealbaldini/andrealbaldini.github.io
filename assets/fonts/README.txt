Permanent Marker (Font Software by Font Diner, SIL Open Font License 1.1)
Download it from Google Fonts (fonts.google.com/specimen/Permanent+Marker), then put these two files in this folder:
  PermanentMarker-Regular.ttf
  PermanentMarker-Regular.woff2   (optional: convert the .ttf with any ttf-to-woff2 tool; the site works with the .ttf alone)
Until then the site uses the fallback handwriting fonts of the visitor's system (Marker Felt, Segoe Print...).
Also keep the font's OFL.txt licence file next to the font files.
